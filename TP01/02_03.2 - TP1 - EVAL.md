## Description

Le TP01 vous demande de constituer un **répertoire personnel de 20 sources de veille technologique**, organisées par catégorie et accompagnées chacune d'une justification de leur pertinence.

Ce n'est pas une liste de favoris — c'est une démonstration que vous savez identifier des sources de qualité, les classer et expliquer pourquoi elles méritent une place dans votre veille.

## Structure attendue

Pour chaque source, vous devrez fournir :

| Champ | Description |
|---|---|
| **Nom de la source** | Titre du blogue, du média, du dépôt, de la newsletter… |
| **URL** | Lien direct vers la source ou le flux RSS |
| **Catégorie** | Type de source (média, blogue, doc officielle, rapport, communauté…) |
| **Langue** | Français / Anglais / Autre |
| **Fréquence de publication** | Quotidienne, hebdomadaire, mensuelle, irrégulière |
| **Justification** | 2–4 phrases expliquant pourquoi cette source est pertinente pour votre veille et comment vous comptez l'utiliser |
| **Évaluation CRAAP** | Note rapide sur les 5 critères (fort / moyen / faible) |

---

## Contraintes

- Minimum **4 catégories différentes** représentées
- Minimum **3 sources en français**
- Maximum **3 sources provenant du même domaine** (ex. : pas 5 sources du même blogue)
- Toutes les sources doivent être **actives** (publication dans les 12 derniers mois pour les sources régulières)

---

## Format de remise

Le TP01 est remis sous forme d'un **fichier Excel** (.xlsx) déposé dans le **canal du cours sur Microsoft Teams**.

- Le fichier doit être structuré sous forme de **tableau formaté** (tableau Excel officiel, pas une simple plage de cellules)
- Une ligne par source, les colonnes correspondent aux champs décrits ci-dessus
- Le tableau doit être lisible et bien structuré — en-têtes clairs, colonnes dimensionnées, retours à la ligne activés pour les justifications

Nommez votre fichier : `TP01_Prenom_Nom.xlsx`
